# Ejercicios - Lección 01

Intenta hacer estos sin mirar el ejemplo. Edita `HolaMundo.java` o crea archivos nuevos.

### Ejercicio 1: Presentación
Crea un programa que imprima:
```
Nombre: [Tu nombre]
Edad: [Tu edad]
Ciudad: [Tu ciudad]
Me gusta aprender Java
```
Pista: usa 4 System.out.println

### Ejercicio 2: Dibujo con texto
Imprime esto exactamente:
```
  *
 ***
*****
  *
```
Usa System.out.println con asteriscos.

### Ejercicio 3: Error a propósito
Cambia el nombre de la clase a `holamundo` (minúscula) pero deja el archivo como `HolaMundo.java` e intenta compilar.
¿Qué error te da? ¿Por qué? (Luego corrígelo)

### Ejercicio 4: print vs println
Haz un programa que con `print` y `println` logre esta salida en EXACTAMENTE 2 líneas:
```
Hola Mundo
Adiós Mundo
```
Pero usando 3 instrucciones print/println. Experimenta.

Cuando termines, avísame y vemos la solución.
