### Cómo compilar y ejecutar (MUY IMPORTANTE)
En esta carpeta, abre una terminal (PowerShell) y ejecuta:

```powershell
# Compilar (crea el .class)
javac 01-fundamentos\HolaMundo.java

# Ejecutar
java -cp 01-fundamentos HolaMundo
```
O si estás DENTRO de la carpeta:
```powershell
javac HolaMundo.java
java HolaMundo
```

> Desde Java 21 ya puedes hacer `java HolaMundo.java` directo sin compilar, pero aprenderemos el método clásico primero.
