# Ejercicios - Lección 08: Métodos

Crea los métodos FUERA del main y llámalos desde main.

### Ejercicio 1: Saludo
Crea `void saludar(String nombre)` que imprima "Hola, [nombre]". Llámalo 3 veces.

### Ejercicio 2: Suma con retorno
Crea `int sumar(int a, int b)` que devuelva la suma. En main guarda el resultado y muestra el doble del resultado usando tu método.

### Ejercicio 3: Es par
Crea `boolean esPar(int n)` que devuelva true si es par (n % 2 == 0). Pruébalo con varios números.

### Ejercicio 4: Mayor de dos
Crea `int mayor(int a, int b)` que devuelva el mayor. Si son iguales devuelve cualquiera. Usa ternario.

### Ejercicio 5: Factorial
Crea `long factorial(int n)` que calcule factorial con for y devuelva el resultado. Prueba con 5 -> 120.

### Ejercicio 6: Área y perímetro
Crea `double areaRectangulo(double base, double altura)` y `double perimetroRectangulo(double base, double altura)`. Pruébalos.

### Ejercicio 7: Sobrecarga
Crea dos métodos `int multiplicar(int a, int b)` y `double multiplicar(double a, double b)`. Llámalos con enteros y decimales.

### Ejercicio 8 (Reto): Método con array
Crea `int maxArray(int[] arr)` que devuelva el mayor del array y `double promedioArray(int[] arr)` que devuelva el promedio. Prueba con `{3, 9, 2, 15, 6}`.

### Ejercicio 9 (Reto): Validar
Crea `boolean esMayorDeEdad(int edad)` y `String categoriaEdad(int edad)` que devuelva "Niño" (<13), "Adolescente" (<18) o "Adulto".
