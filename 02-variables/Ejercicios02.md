# Ejercicios - Lección 02

### Ejercicio 1: Ficha personal
Crea variables para: nombre (String), edad (int), altura (double), inicial (char), esMayorDeEdad (boolean).
Imprime todo en una frase bonita:
"Me llamo X, tengo Y años, mido Z metros, mi inicial es W. ¿Mayor de edad? true/false"

### Ejercicio 2: Intercambio de valores
Declara `int a = 10; int b = 20;`
Intercambia sus valores (que a valga 20 y b valga 10) usando una variable temporal `aux`.
Imprime antes y después.

### Ejercicio 3: Calculadora simple
Declara `int num1 = 8; int num2 = 3;`
Calcula y muestra: suma, resta, multiplicación, división (como double) y resto (%).
Pista: para división decimal haz `(double) num1 / num2`

### Ejercicio 4: Constante
Declara una constante `final int DIAS_SEMANA = 7;` y intenta cambiarla. Observa el error.
Luego calcula cuántos días hay en 4 semanas.

### Ejercicio 5 (Reto): var
Declara 3 variables usando `var`: una con texto, una con decimal, una con booleano.
Imprime su valor y adivina qué tipo detectó Java.
